ADAS Camera Software Test Dashboard

A professional automotive software test dashboard built for validating an ADAS surround-view camera ECU on a commercial truck platform. The system integrates five camera channels (front, rear, left, right, cargo/truck-bed), twelve ultrasonic parking sensors (USS), and autonomous driving and trailer-assist feature modules. The interactive demo simulates real-time test case execution with animated mock camera feeds, live sensor overlays, test suite management, and a status board tracking pass, fail, in-progress, and not-executed states across all ADAS subsystems.
