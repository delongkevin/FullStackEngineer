AUTOSAR ECU Software Component Studio

A professional AUTOSAR ECU software component development and diagnostics studio targeting a SurroundView Camera ECU. The tool visualizes the full AUTOSAR Classic architecture: an animated SWC composition canvas showing 7 software components connected via RTE, a layered BSW stack from MCAL to Application, a UDS ISO 14229 diagnostic session with DTC freeze-frame viewer, an RTE port inspector showing all provided/required interfaces with live values, and an A2L-style calibration parameter editor with range sliders and NvM write control.
