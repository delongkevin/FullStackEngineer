Enterprise ERP Workbench

Enterprise ERP Workbench is a Windows desktop business systems demo built with C# and the .NET Framework using WPF, MVVM, domain-driven design, dependency injection, and a service-oriented architecture. It models a manufacturing ERP/MRP environment with work orders, inventory, purchasing, production scheduling, and support workflows. The project highlights SQL Server schema design, DDL and DML scripts, stored procedures, reporting, data correction tools, bug-fix triage, and documentation practices that align with enterprise software support and delivery responsibilities.
