Real Estate Marketplace App

A full-stack real estate marketplace mobile application built with React Native and Expo. It includes secure authentication, advanced property filtering, favorites management, tour booking workflows, and user profile updates. The backend provides REST APIs for properties, bookings, and user management. The portfolio demo summarizes workflows and links to release artifacts.
