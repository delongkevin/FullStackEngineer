CAN-FD Network Analyzer & Protocol Decoder

A professional automotive CAN-FD network analysis tool simulating live bus traffic across 8 ECU nodes. The dashboard features a scrolling frame trace with decoded DBC signal names, a semicircle bus load gauge, real-time signal waveform plots for RPM/Speed/Throttle/ADAS distance, full byte inspector, and error statistics. Supports 500Kbps CAN and 2Mbps CAN-FD bitrates with fault injection and .asc log export compatible with Vector CANalyzer format.
