Fitness Tracker App

FitTrack is a comprehensive cross-platform fitness tracking application built with React Native and Expo. Log workouts (running, cycling, swimming, gym, yoga, walking), monitor real-time health metrics (heart rate, steps, calories, water, sleep) via Apple HealthKit and Google Fit, sync with wearable devices (Apple Watch, Wear OS, Fitbit), set and track fitness goals with visual progress, and view weekly performance summaries with interactive charts. The app features full user authentication, detailed profile management with BMI calculation, and a professional Material Design UI optimized for iOS and Android.
